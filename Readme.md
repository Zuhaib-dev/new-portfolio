> **HealOS** is a mission-critical, enterprise-grade healthcare management system designed to eliminate clinical administrative friction. It centralizes patient records, doctor appointment scheduling, staff duty rosters, billing pipelines, and real-time ICU/ward bed occupancy.

#### 🛠️ Tech Stack & Architecture
- **Frontend:** Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Framer Motion
- **State Management:** Zustand (Client state), TanStack React Query (Server caching & optimistic updates)
- **Backend & APIs:** Node.js, Express.js (RESTful APIs with strict validation)
- **Database & Realtime:** MongoDB & Mongoose, Socket.io (instant Pub/Sub vitals & bed updates)
- **Security & Payments:** JWT Role-Based Access Control (Admin/Doctor/Patient), Razorpay Payment Gateway

## 🤖 Agentic Interfaces & Machine Manifests

Autonomous AI agents, LLMs (GPT-4o, Claude 3.5/3.7, Gemini, Perplexity), and coding assistants can interact with this site through standard machine-readable interfaces:

| Manifest / Interface | Endpoint | Description |
|---|---|---|
| **Plaintext LLM Manifest** | [`/llms.txt`](https://www.zuhaibrashid.com/llms.txt) | LLM-optimized summary of skills, background, case studies, and navigation |
| **Model Context Protocol (MCP)** | [`/api/mcp`](https://www.zuhaibrashid.com/api/mcp) | Live JSON-RPC 2.0 Streamable HTTP MCP server exposing tools (`get_github_stats`, `get_projects`, `get_blog_posts`) & resources |
| **MCP Server Manifest** | [`/.well-known/mcp.json`](https://www.zuhaibrashid.com/.well-known/mcp.json) | Standard MCP tool catalog and metadata |
| **OpenAPI 3.1.0 Spec** | [`/openapi.json`](https://www.zuhaibrashid.com/openapi.json) | Fully typed OpenAPI 3.1 specification for function calling |
| **Agent Operating Guide** | [`/agents.md`](https://www.zuhaibrashid.com/agents.md) | Guidance and policies for autonomous AI crawler navigation |
| **Authentication Policy** | [`/auth.md`](https://www.zuhaibrashid.com/auth.md) | WorkOS 7-step walkthrough, Zero-Auth Free Tier policy, and sandbox details |
| **Agent Resource Discovery** | [`/.well-known/ard.json`](https://www.zuhaibrashid.com/.well-known/ard.json) | ARD 1.0 catalog with domain-anchored `urn:air:zuhaibrashid.com:*` identifiers |
| **A2A Agent Card** | [`/.well-known/agent-card.json`](https://www.zuhaibrashid.com/.well-known/agent-card.json) | A2A standard agent card with capabilities and provider info |
| **API Catalog (RFC 9727)** | [`/.well-known/api-catalog`](https://www.zuhaibrashid.com/.well-known/api-catalog) | RFC 9727 linkset profile (`application/linkset+json`) |
| **ChatGPT / AI Plugin** | [`/.well-known/ai-plugin.json`](https://www.zuhaibrashid.com/.well-known/ai-plugin.json) | OpenAI plugin manifest format |
| **Dynamic `.md` Twins** | `/*.md` (e.g. `/developers.md`) | Automated Markdown representation for all content pages via middleware |
| **Agent View Mode** | `/?mode=agent` | High-density semantic view for agents |

## 🚀 Getting Started

### Prerequisites

- **Node.js** ≥ 18
- **npm** or **pnpm**

### Installation

```bash
# Clone the repository
git clone https://github.com/Zuhaib-dev/new-portfolio.git
cd new-portfolio

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Fill in your Spotify, email, and other credentials

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
